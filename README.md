# devops_final_project

# Procedure 

•	Step 1: Install Minikube to setup up a local Kubernetes cluster.
•	Step 2: Install and configure Helm, the Kubernetes package manager.
•	Step 3: Add Prometheus and Grafana Helm repositories.
•	Step 4: Deploy Prometheus on the Kubernetes cluster using Helm charts to collect metrics.
•	Step 5: Deploy Grafana using Helm and configure it to use Prometheus as a data source.
•	Step 6: Import pre-build Kubernetes dashboards into Grafana for visualizing cluster performance.
•	Step 7: Verify real-time metrics collection and dashboard visualization.
